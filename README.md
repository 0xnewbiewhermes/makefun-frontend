A fast, read-only make.fun frontend in plain static files (ES modules + one stylesheet, no build step, no framework): the live bounty board, each bounty's page with its live-pot rewards, its leaderboard and every account's public profile, on hash routes (`#/`, `#/bounty/<slug>`, `#/bounty/<slug>/leaderboard`, `#/u/<handle>`). The board ships in a ~13 KB gzipped first load; the other views load by `import()` on first use. API answers are cached in memory, revalidated with ETag / If-None-Match (stale-while-revalidate), and views patch the DOM in place on refresh.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
